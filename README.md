# HTML & CSS Mini Portfolio 🌐

A personal mini portfolio website built with HTML and CSS as part of my web development learning journey.

## About the Project

This project is a simple portfolio website created to practise structuring web pages with HTML and styling them with CSS. It includes images and a JavaScript file that I plan to develop further.

## Technologies Used

- HTML5
- CSS3
- JavaScript (planned improvements)

## Project Files

- `index.html` — The main webpage.
- `styles.css` — The website's styling.
- `my_image.jpg` — Personal image used in the project.
- `project1.jpeg` to `project5.jpeg` — Project images (PLACEHOLDERS).
- `web_javascipt.js` — JavaScript file for future functionality.

## How to View

1. Download or clone this repository.
2. Open `index.html` in your web browser.

## What I Learned

- Structuring webpages with HTML.
- Styling and designing layouts with CSS.
- Organising website files and images.
- Building a foundation for interactive web development.

## Future Improvements
