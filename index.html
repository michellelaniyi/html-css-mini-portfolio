My Learning Journey

I started learning python 7 months ago and all I have to say is "it's been a wild ride".
I've always wanted to learn programming ever since i was younger, my brother even got me a laptop.
But, I didn't take it seriously then, and it's sometg I still regret.

But, I've stopped thinking about the past and I'm looking to my future. For the past 7 months, i've been learning python and I've come to know a lot of things.
I've learnt the fundamentals of python such as variables, conditionals, loops, type-casting, lists, etc.
Advancing from the basic fundamentals, I moved to more advanced concepts such as Object Oriented Programming (OOP),
randomization, using external packages like pandas to create projects like a squirrel data sorter.

I've also created games such as "Turtle crossing", "Turtle race", "Ping Pong game" etc.
Eventually, I learnt how to design Graphical User Interface (GUI),
where I learnt to use tkinter to create interfaces and eventually created my first ever GUI Calculator.

Although, I still have a lot to learn, I am proud of myself of how far I've come.
And I can't wait to see what's in store for me as I continue my tech, learning and content creation journey
